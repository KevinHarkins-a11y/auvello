# Auvello

Starter website for Auvello — premium fabric-wrapped acoustic panels.

Plain HTML/CSS/JS, no build step, ready to deploy on Netlify.

## Structure

- `index.html` — homepage
- `css/styles.css` — styles
- `js/main.js` — small scripts
- `favicon.svg` — monogram favicon
- `netlify.toml` — Netlify build/publish config

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static
file server, e.g.:

```
npx serve .
```

## Deploy

Connect this repo to Netlify (or drag-and-drop the folder into Netlify) —
the `netlify.toml` publishes the project root as-is, no build command needed.
